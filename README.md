
### Version 0.0.0.0.01  work in progress
<p>
A rail-station-network graph-oriented, Python 3.13 train-schedule-centric trip-link generating app. Unlike 
standard travel engines that force a user-schedule-centric ticketing approach, this system maps travel 
entirely around physical US rail topologies, Named Trains (e.g., Coast Starlight, Empire Builder), and their schedules. 
It validates 100% rail-legal itineraries via networkx before generating parameterized HTTPS Requests that 
safely hand off actual ticketing and final checkout to the official Amtrak payment gate.
</p>
<p>
An example trip-link might define ticketing two adults for a round trip between Flagstaff, Arizona and 
Reno, Nevada (via Los Angeles and Sacramento, Ca.) between dates A and B.
</p>
